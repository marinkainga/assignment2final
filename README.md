# assignment2final

Assignment 2: analyzing song lyrics from singer-songwriter Laufey, and research the use of semantics to see if most of the songs are about love. The aim for this study is to understand the songwriting by Laufey. The target audience for this small study are Laufey fans, who want to get a deeper or more linPrguistic understanding of her lyrics. 

This repository is set up as following:
the data file includes all the .txt files of the song lyrics. The ipynb file contains the python code used. laufeymetadata.csv contains all the metadata for the analysis. laufey_lyrics_with_spaCy_tags.csv contains the .csv files with all the spaCy tags that are created after the analysis in Python.

The corpus exists of song lyrics from all the EP's and studio albums. The songs were chosen based on the four most streams of each EP/Album. The corpus includes the song name, album name, release date and the lyrics. In the full analyzed data, Tokens, lemmas (lemmatized text) and parts-of-speech (POS) of all the tokens in this document are also included. It also includes the columns Proper_Nouns, which includes the proper nouns in the song lyrics. Named_Entities described the named entities. The corpus was used to investigate semantic use in the songwriting, and to analyze if most of the songs are about love or other subjects. The data was collected via Google, where the song lyrics was copied and pasted into a .txt file, contained in a file named data. 

Tokens are the individual words of text. By using tokenization, each song lyrics is split into individual words, which helps with the overall semantic analysis of each words. Lemmanization is the retrieval of the root word. This tool helps with the linguistic semantic analysis of each word, to see how it is used in a certain context. Part of speech looks at the syntactic function of each word, and categorizes it in a subjec, object, verb etc. Proper nouns include the names of places, things or person. All these columns are useful to understand the semantic tone of the songwriting by Laufey. 

The metadata csv files contains columns ID, TITLE, ALBUM, RELEASE DATE, LYRICS.
The ID column was given a number started from 1. The TITLE column contains the title of the song. ALBUM contains the title of the album. RELEASE DATE contains the release date of the album. The LYRICS column contains the entire lyrics for each song. For the last album, Bewitched: The Goddess edition, the four most streamed songs from the extra songs that were added to the album were chosen, which were not on the original Bewitched album. 

The final csv file, named laufey_lyrics_with_spaCy_tags.csv contains all the metadata in the original metadata csv file and also contains the spacy analysis, including the tokens, lemmas, part of speech and proper nouns. 

From the analysis, it is clear that Laufey uses a lot of adjectives. These are words that are used to describe something, or someone. When looking at proper nouns, almost every song includes a proper noun about love. Bewitched, baby, darling, cupid are just a few examples of a proper noun that is used  in 11 of the 14 songs. Pronouns are also used very often, which can indicate that the lyrics are talking about someone or are addressed to someone. This could be interpreted as a love song. The graph also shows that adjectives are used much less often than verbs. Nouns and verbs are almost equal. However, this analysis unfortunately doesn't tell us much about the semantics of the lyrics, as verbs, nouns and adjectives are always in a sentence in the English language. However, the proper nouns do show that themes around love are mentioned quite often. This could mean that love is a central theme in a lot of her songs.
